# 03 有限狀態機（FSM）

先用鍵盤模擬攝影機，不需要硬體或第三方套件。

## 執行

在專案根目錄執行：

```bash
python3 03_fsm/main.py
```

輸入 `1` 表示有物品、`0` 表示沒物品、`q` 結束。
連續 3 次有物品才告警，占用中不重複告警；沒物品就立即解除。

## 試試看

依序輸入，每輸入一個值就按 Enter：

- `1、1、0`：短暫占用，計數歸零。
- `1、1、1、1`：成立事件，只告警一次。
- `0`：解除事件，回到正常。

`state` 記住目前狀態，`blocked_count` 記住連續占用次數。
修改 `ALERT_THRESHOLD = 3`，觀察告警門檻如何改變。
