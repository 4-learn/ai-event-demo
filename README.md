# AI 事件管理系統

這是一個給 Python 初學者的課程示範。

我們用「通道被物品擋住」的故事，看看 Python 如何串起攝影機、事件判斷、LINE 通知與 AI 報告。

## 你會看到什麼？

1. 用有限狀態機，判斷事件何時開始與結束。
2. 用 YOLO 辨識物件，持續占用才發出 LINE 通知。
3. 用爬蟲蒐集規範，透過 RAG 查詢並附上來源。
4. 讓 Agent 查詢歷史紀錄、計算統計，整理七天報告。

## 從哪裡開始？

先看懂有限狀態機，再逐步加入其他功能。
第一階段不需要 ESP32-CAM，也不需要先理解所有 AI 技術。

## 目前分支：09_rag

這個分支從 08 接續：先檢索教學規範，再由 LLM 回答並附上原文來源。

## 範例程式

- [09 規範問答](09_rag/)：本機語意檢索、LLM 回答與引用檢查。
- [08 網路爬蟲](08_crawler/)：擷取八條教學規範，保留條號與來源。
- [07 事件儲存](07_logging/)：解除後追加一筆 CSV，附七天模擬歷史。
- [06 即時通知](06_line/)：事件成立時發送 LINE。
- [05 區域與時間過濾](05_roi/)：ROI 底部中心點判斷與三秒計時。

- [04 影像辨識](04_yolo/)：每秒取樣一次，連續三個取樣有椅子才告警。

- [03 有限狀態機](03_fsm/)：用鍵盤輸入，理解狀態、計數與告警門檻。

## 建立環境（選用）

03 不需要第三方套件，後續章節使用 requirements.txt 安裝套件：

```bash
python3 -m venv .env
source .env/bin/activate
python -m pip install -r requirements.txt
```

`.env/` 是這台電腦的虛擬環境，不會上傳到 GitHub。

LINE 與 OpenAI 金鑰放在根目錄 config.env，已加入忽略清單。09 會產生少量 API 費用；先看章節 README 與已知限制。
