# 05 感興趣區域與時間過濾

接續 04：只計算通道 ROI 內的椅子，持續占用 3 秒才告警。

- `main.py`：設定四個 ROI 座標、告警秒數，管理有限狀態機。
- `detector.py`：每秒取樣，用 YOLO 找椅子，判斷辨識框底部中心點是否在 ROI 內。
- 座標對應 1280 × 720 的原影片；更換影片或攝影機時需要重設。
- ROI 邊界算占用；淨空立即解除。影片結束只停止讀取，不代表解除。

沿用 04 的影片、模型與根目錄 requirements.txt，在 repo 根目錄執行：

```sh
python 05_roi/main.py
```

目前素材為合成教學影片：空通道 → 椅子在通道內 → 空通道。
尚未包含椅子在 ROI 外的片段。
